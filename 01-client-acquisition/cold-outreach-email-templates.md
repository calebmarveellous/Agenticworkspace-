# Cold Outreach Templates — Direct-Response, ICP-Matched

Rules for every send: (1) personalize the [BRACKET] fields with real research, never leave a bracket unfilled, (2) one CTA per email, (3) no more than 90 seconds to read, (4) subject line under 6 words, (5) never claim a stat you can't back up.

**STANDING RULE (locked, applies to every email/application below):** lead with the value I'd bring to *them* — a short, specific list of what I'd help them achieve — never with a name-drop of past clients as the hook. Past work (Zonia Hub, Suncious Foods, Luscents, etc.) is supporting proof at most, placed after the value list, never the opening line. If a template below still leads with a client name, fix it before sending — it's out of date against this rule.

**STANDING RULE — DELIVERY FORMAT (locked):** every new client-acquisition prospect from here forward gets the premium template look, sent as **inline HTML in the email itself** (Gmail `htmlBody`) — never a PDF/image attachment (that adds friction: recipient has to open a file before reading the pitch) and never plain text. Palette: light-purple background (#F5F0FC), deep-purple header/footer bands (#3B0A5C), gold text accents (#E8C866) — matches Canva design ID `DAHUsqw-l7o` (https://www.canva.com/d/HNFOyAPVqD5Qoto), which remains the visual reference/master copy. Workflow per new prospect: (1) personalize the greeting/opening line and the 3-point value list for that prospect's research, (2) build inline-styled HTML (table-based, inline `style=` attributes — not a `<style>` block, for email-client compatibility) matching the palette above, (3) send via `htmlBody` with a plain-text `body` fallback. Exception: never resend to a prospect already contacted same-day just to switch format — that's a duplicate touch, not an upgrade. Apply starting with the *next* untouched prospect.
